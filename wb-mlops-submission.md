1. One of my most complex inference challenges involved a system for eSports performance analysis, where preprocessing was a bottleneck. It required fusing biometric streams (EEG, PPG, Eyetracking, etc.) of variable frequency with CV outputs from game footage. Along with graceful handling of missing data, one key optimization was moving frame labeling to the GPU to maintain an ~60fps throughput.

2. At UCSF, I inherited a multi-stage radiomics pipeline which required total reprocessing whenever a metric changed, and re-segmenting an ROI invalidated downstream data with no way to track run-states. I used MongoDB to track and version processing stages per case. Mapping these state dependencies allowed updates to propagate only to affected stages, which improved efficiency and reproducibility.
